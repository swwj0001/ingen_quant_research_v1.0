This week, I primarily completed the research design and data download program. The most difficult decision was whether to use the current S\&P 500 list or the actual list for each period when studying past stock performance. Using the current list is more convenient, but it misses companies that were previously in the index but have since dropped out, potentially biasing the research results towards those that remain. I ultimately chose to use the historical constituent stock list to ensure that the stocks studied each month are as relevant as possible to the situation at that time. However, having a historical list doesn't guarantee that data for every stock can be found.

The first full run requested 847 historical stock codes, generating five tables: stock pool, price, financials, macroeconomic data, and factors. After reviewing the reports, I found that some stocks lacked prices, and some lacked corresponding company numbers, with older data being more incomplete. For example, only about 64% of the stocks had price data available in January 2010, while about 99% were available in September 2026. This indicates that the data we have now is incomplete, and some earlier companies may not have been included. My solution is to retain the historical list while recording which stocks and months lack data, and not to fill in missing returns as zero. Some download failures might be due to a stock name change or a program issue; they shouldn't be automatically assumed the company has been delisted. When using this data later, it's necessary to specify which samples weren't used and what impact this might have on the results.

This experience taught me that after the program runs, it's crucial to examine the actual data obtained. When comparing models in the future, I will have different models use the same stocks and months to avoid mistakenly assuming a particular model is better simply because different data was used.
