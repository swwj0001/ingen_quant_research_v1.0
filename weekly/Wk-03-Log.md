This week, I followed the approach from the Oxford Credit Card Default Project, comparing models like Random Forest, Gradient Boosting Tree, and AdaBoost on the same dataset and with the same split. While the credit card project aimed to predict default, this project aimed to predict stock returns. I was more concerned with whether the model could prioritize stocks with higher returns later on. Therefore, I mainly looked at how consistent the predicted ranking was with the actual return ranking, and also at the difference in actual returns between the top and bottom groups of stocks. To simulate the situation when making predictions each month, I selected parameters annually using the validation data at that time, and then retrained the model using the available data for each month. In the results, Random Forest had the highest average Rank IC, which became negative after removing 2016, and the top-ranked stock group had an average monthly return 0.393 percentage points lower than the last group. Combining the three best-performing models in the validation process, the overall performance was similar to the OLS-3 benchmark. There were also 33 Elastic Net trials where Rank IC couldn't be calculated because they gave identical prediction scores; I included these in the total number of trials. The most noticeable takeaway this week is that the high-performing results identified during validation may not be seen in later months. Next week, when adding text features, I will continue using this segmentation method to see if the new information can bring about a more stable improvement.
